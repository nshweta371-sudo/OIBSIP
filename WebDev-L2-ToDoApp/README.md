# To-Do Web App

## 📌 Project Overview

This project is an interactive To-Do Web Application developed as part of the Oasis Infobyte Web Development Internship – Level 2, Task 3.

The application allows users to create and manage their daily tasks through a simple and responsive interface.

---

## 🎯 Objective

The objective of this project is to develop an interactive to-do list application that allows users to:

- Add tasks
- Complete tasks
- Edit tasks
- Delete tasks
- View pending tasks
- View completed tasks

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

---

## ✨ Features

### 1. Add Task

Users can enter a task in the input field and click the "Add Task" button.

New tasks immediately appear in the Pending Tasks section.

### 2. Mark Complete

Each task has a completion button.

When a task is marked complete, it moves from the Pending Tasks list to the Completed Tasks list.

### 3. Edit Task

Each task has an Edit button that allows the user to modify the task text.

### 4. Delete Task

Each task has a Delete button that permanently removes the task.

### 5. Task Counters

The application displays:

- Number of pending tasks
- Number of completed tasks

### 6. Timestamp

Each task displays the date and time when it was added.

### 7. Local Storage

Tasks are stored using browser localStorage.

Therefore, tasks remain available even after refreshing the page.

### 8. Empty State

Friendly messages are displayed when there are no pending or completed tasks.

### 9. Responsive Design

The application works on:

- Desktop
- Laptop
- Tablet
- Mobile
