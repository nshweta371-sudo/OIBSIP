# Dr. A.P.J. Abdul Kalam – Tribute Page

## 📌 Project Overview

This project is a responsive tribute page dedicated to Dr. A.P.J. Abdul Kalam, one of India's well-known scientists and former President.

The page presents his biography, important milestones, achievements, awards, and an inspirational quote in a clean and visually engaging layout.

This project was developed as part of the **Oasis Infobyte Web Development Internship – Level 2, Task 2**.

---

## 🎯 Objective

The objective of this project is to design and build a visually engaging tribute page using:

- HTML5
- CSS3
- JavaScript

The page is designed to be responsive and accessible on different screen sizes.

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the webpage
- **CSS3** – Styling, layout, colors, responsive design and animations
- **JavaScript** – Basic webpage interaction
- **Wikimedia Commons** – Image source

---

## ✨ Features

The tribute page includes:

- Hero section with Dr. A.P.J. Abdul Kalam's name
- Inspirational tagline
- Prominent image
- Biography section
- Timeline of important achievements
- Major awards section
- Inspirational quote
- Responsive layout
- Different background colors for sections
- Serif and sans-serif fonts
- Hover effects on cards and buttons
